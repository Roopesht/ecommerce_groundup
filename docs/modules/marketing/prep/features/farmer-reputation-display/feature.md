# Feature: Farmer Reputation Display

## Summary
Farmers can view their aggregate rating, customer reviews, and feedback. This reputation system is central to building trust in the marketplace; farmers see what customers value and can improve based on feedback.

## User Story
As a farmer, I want to view my customer reviews and aggregate rating so that I can understand customer feedback and improve my operations.

## Acceptance Criteria
- Farmer can navigate to their profile or "My Reputation" section
- Farmer can view their aggregate rating (displayed as stars)
- Farmer can see the count of reviews received
- Farmer can view a list of customer reviews with customer name, rating, review text, and date
- Farmer can see reviews sorted by recency or rating (optional sorting features)
- Farmer can understand common feedback themes or trends from reviews
- Farmer cannot edit or delete customer reviews
- Farmer can view which produce items customers reviewed
- Farmer's aggregate rating is displayed on their public profile (visible to customers)
- Farmer can filter reviews by produce type (optional)

## Priority
High — This is a must-have feature; farmer reputation is a primary trust signal and directly influences customer purchasing decisions.

## Dependencies
user-registration, user-login, farmer-profile-management, order-review-rating
