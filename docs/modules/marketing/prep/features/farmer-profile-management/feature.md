# Feature: Farmer Profile Management

## Summary
Farmers can create and maintain a public profile that showcases their identity, farming practices, location, and certifications. This profile is visible to customers and builds trust through transparency about farming methods and farmer story.

## User Story
As a farmer, I want to create and edit my profile with information about my location, farming practices, and credentials so that customers can understand who I am and how I farm.

## Acceptance Criteria
- Farmer can navigate to profile creation or editing page
- Farmer can enter location (city/village in Bangalore or Cochin)
- Farmer can describe farming practices (organic methods, techniques, story)
- Farmer can add certifications or credentials (text field, self-reported)
- Farmer can upload a profile photo
- Farmer can submit the profile form
- System saves and validates all fields
- System displays confirmation that profile is now live and visible to customers
- Farmer can edit their profile at any time
- Changes to profile are immediately visible to customers
- Farmer can view their own profile as customers see it

## Priority
High — This is a must-have feature for farmers to list produce and build credibility; it directly supports user acquisition and trust.

## Dependencies
user-registration, user-login
