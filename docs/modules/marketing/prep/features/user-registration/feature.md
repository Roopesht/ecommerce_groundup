# Feature: User Registration

## Summary
Users (both farmers and customers) can create accounts on the platform with their basic information. This is the gateway to accessing the marketplace and enables role-specific features like listing produce (farmers) or placing orders (customers).

## User Story
As a new user, I want to sign up for the platform with my email and password so that I can access the marketplace and use role-specific features.

## Acceptance Criteria
- User can navigate to a sign-up page or form
- User can enter email address and password
- User can select their role (Farmer or Customer)
- System validates email is in valid format and not already registered
- System validates password meets minimum requirements (length, complexity)
- User can submit the form
- System creates account and stores securely
- User receives confirmation (email or in-app message)
- User can proceed to log in after successful registration
- System prevents duplicate registration with same email address

## Priority
High — Registration is the foundation; without it, no user can access the platform.

## Dependencies
None
